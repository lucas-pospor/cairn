Local-first Markdown notes

Cairn is a free, open-source notes app for Linux, Windows and Android. A notebook is an ordinary folder of Markdown files that Cairn reads and writes directly, so any other editor, Git or backup tool works with it too. Sync between your devices is optional and end-to-end encrypted, through a small server you run yourself.

Features

  • Plain files

    A notebook is a folder of .md files. Open it in another editor, put it under Git, or back it up however you like.

  • Live Preview

    Markdown renders as you type. Source mode, reading view and a side-by-side split each take one click.

  • Links and embeds

    Wikilinks with autocomplete, embedded notes, images, audio and video, and backlinks for every note.

  • Search and graph

    A quick switcher, a command palette, full-text search with tag: and path: filters, and a graph view.

  • Sync through your own server

    End-to-end encrypted. Edits that collide become conflict copies, and version history restores older versions.

  • Six themes

    Three light and three dark, two of them high-contrast, plus an accent color, fonts and CSS snippets.

  • Templates and daily notes

    Optional core plugins, and a small plugin API that runs each plugin in its own sandbox.

  • Keyboard

    Every command can have a hotkey, and the file tree and the graph work from the keyboard.

Platforms

  • Linux: .deb, .rpm and AppImage, for x86_64.
  • Windows 10 and 11: an installer, for x86_64.
  • Android 7.0 or later: an APK.
  • Sync server: a Docker image for x86_64, or build it from source.

There is no macOS build and no iOS app.
