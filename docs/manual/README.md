# Cairn manual

Cairn is a local-first Markdown notes app for Linux, Windows and Android. A notebook is an ordinary folder of `.md` files, and Cairn reads and writes those files directly. Sync between your devices is optional and end-to-end encrypted, through a small server you run yourself.

- [Getting started](getting-started.md): install Cairn and open a notebook.
- [Notebooks and files](notebooks-and-files.md): the file tree, file names, images and other files, settings, symlinks.
- [Editing](editing.md): Live Preview, tabs and autosave, panels, the word count, hotkeys.
- [Links and embeds](links-and-embeds.md): wikilinks, embeds, attachments.
- [Search and graph](search-and-graph.md): the quick switcher, the command palette, full-text search, the graph view.
- [Themes and appearance](themes-and-appearance.md): the six themes, the accent color, fonts, CSS snippets, zoom.
- [Sync and the sync server](sync.md): run a server, set up each device, conflicts, version history.
- [Core plugins](core-plugins.md): Templates, Daily notes, Unique note creator, Random note.
- [Plugins](plugins.md): write a plugin, its API, turning it on.
- [Android](android.md): install the APK, notebooks on a phone, sync on the local network.
- [Windows](windows.md): the installer, app data, deleted notes, the log, file names.
- [Building from source](building.md): build the desktop app and the Android app.
- [Known limits](known-limits.md): what Cairn does not do yet, or does differently.
- [Release notes](../RELEASE_NOTES.md): what changed in each version.
